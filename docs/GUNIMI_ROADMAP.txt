TIER 1 — KRITICKÉ BUGY & CHÝBAJÚCE ZÁKLADY
(Blokuje denné používanie — riešiť ako prvé)
--------------------------------------------------------------------------------

  [ ] 1.  Custom deal stages
          - Aktuálne sú pipeline stages hard-coded
          - Každý tím má iný workflow (Sales vs. Nákup vs. Legal)
          - Potreba: owner vie nastaviť vlastné názvy fáz
          - Odhadovaný čas: 2 dni

  [ ] 2.  Custom fields na entitách
          - HR chce "Dátum nástupu", Legal chce "Číslo zmluvy"
          - Potreba: owner vie pridať text/date/number/select polia
          - Odhadovaný čas: 3–4 dni

  [ ] 3.  In-app notifikácie
          - Keď ti niekto priradí úlohu — žiadna notifikácia
          - Keď deal zmení stage — žiadna notifikácia
          - Potreba: bell icon v topbare, notification feed
          - Odhadovaný čas: 2 dni

  [ ] 4.  Email notifikácie (transactional)
          - Notifikácia keď si pozvaný do workspacu (existuje čiastočne)
          - Digest — denný/týždenný prehľad úloh
          - Odhadovaný čas: 2 dni

  [ ] 5.  Recurring / opakované úlohy
          - Každotýždenný report, mesačný review
          - Potreba: repeat interval (daily/weekly/monthly/custom)
          - Odhadovaný čas: 1 deň

  [ ] 6.  Deal — pôvodná suma + zaplatené + zostatok
          - Pre vymáhanie pohľadávok a komplexné dealy
          - Aktuálne len jedna hodnota (value)
          - Odhadovaný čas: 1–2 dni (+ DB migrácia)

  [ ] 7.  Dátum premlčania / expiry date na dealoch
          - Pre právne, pohľadávky, zmluvy s expiráciou
          - Odlišné od expected_close_date
          - Odhadovaný čas: 1 deň

  [ ] 8.  Priority / urgency flag na kontaktoch a firmách
          - Označiť VIP klienta, urgentný prípad
          - Odhadovaný čas: 1 deň

TIER 3 — ENTERPRISE (Blokuje predaj veľkým firmám)
--------------------------------------------------------------------------------

  [ ] 19. Public REST API
          - Integrácia s SAP, ERP, interné systémy zákazníka
          - API keys per workspace, rate limiting
          - Odhadovaný čas: 2–3 týždne

  [ ] 20. Webhooks
          - "Keď sa vytvorí deal → POST na váš endpoint"
          - Odhadovaný čas: 1 týždeň

  [ ] 21. SSO / SAML (Azure AD, Okta, Google Workspace)
          - Každá firma 200+ ľudí to vyžaduje
          - Odhadovaný čas: 1–2 týždne (Supabase SAML podporuje)

  [ ] 22. Advanced permissions
          - Field-level — obchodník nevidí margin
          - Read-only users — stakeholderov len na čítanie
          - Odhadovaný čas: 1 týždeň

  [ ] 23. SLA & Uptime guarantee
          - 99.9% uptime SLA — enterprise zmluvy to vyžadujú
          - Monitoring, incident response proces
          - Odhadovaný čas: proces + infraštruktúra

  [ ] 24. SOC 2 Type II certifikácia
          - Bez toho žiadna banka ani veľká firma nepodpíše
          - 6–12 mesiacov procesu, externý audítor
          - Odhadovaný čas: dlhodobé

  [ ] 25. Data residency — EU-only hosting
          - GDPR-sensitive odvetvia (banky, zdravotníctvo, legal)
          - Supabase EU region + Vercel EU deployment
          - Odhadovaný čas: 1 týždeň (config)

  [ ] 26. Dedicated instances (on-premise / VPC)
          - Alza-scale — nechcú byť na shared infrastructure
          - Odhadovaný čas: architektonické rozhodnutie

  [ ] 27. GDPR tooling
          - Right to erasure — vymazať všetky dáta konkrétnej osoby
          - Data export per contact (Article 20)
          - Odhadovaný čas: 1 týždeň

  [ ] 28. Billing & Subscription management
          - Stripe integrácia, plány, invoicing
          - Odhadovaný čas: 2 týždne

  [ ] 29. Multi-language rozšírenie
          - DE, PL, HU — expanzia do DACH a okolie
          - Odhadovaný čas: 1 deň per jazyk (ak máš prekladateľa)
