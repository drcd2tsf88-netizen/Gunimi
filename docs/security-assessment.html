Celkový záver: Platforma je bezpečná pre bežné obchodné použitie Gunimi spĺňa štandardy bežné pre SaaS platformy kategórie B2B (CRM, projektové riadenie, knowledge management). Bezpečnostná úroveň je porovnateľná s nástrojmi ako Notion, HubSpot alebo monday.com. Platforma je vhodná na ukladanie obchodných kontaktov, firemných dát, dealov, úloh, poznámok a internej komunikácie.

1. Infraštruktúra a hosting

Aplikačný server — Vercel

Vercel beží na infraštruktúre Amazon Web Services (AWS). Je certifikovaný podľa SOC 2 Type II a ISO 27001. Každý request beží v izolovanom serverless kontajneri — neexistuje zdieľaná pamäť medzi požiadavkami. Vercel zabezpečuje automatické OS/kernel aktualizácie, TLS šifrovanie a DDoS ochranu.

Databáza — Supabase (PostgreSQL)

Dáta sú uložené v Supabase (PostgreSQL na AWS). Supabase je SOC 2 Type II certifikovaný. Databáza beží v EU regiónoch. Všetky pripojenia sú šifrované (TLS 1.2+). Dáta v pokoji sú šifrované pomocou AES-256.

2. Prístup k dátam a izolácia

Gunimi využíva Row Level Security (RLS) — bezpečnostný mechanizmus priamo v databáze, ktorý vynucuje, že každý používateľ môže čítať a upravovať výhradne dáta svojho workspacu. Toto pravidlo platí na úrovni databázy — nie len v aplikačnom kóde. Ak by aplikačný kód obsahoval chybu, RLS stále zabraňuje úniku dát medzi workspacmi.

  • Každý workspace je plne izolovaný od ostatných
  • Používateľ vidí len dáta svojho workspacu — vynútené priamo v databáze (RLS)
  • Servisný kľúč (service role) je dostupný len na serveri, nikdy klientovi
  • Prístupy do admin konzoly sú chránené dvojúrovňovým overením (session + platform_role)
  • Zakladateľský panel je chránený hardcoded overením konkrétnej emailovej adresy

5. Bezpečnostné HTTP hlavičky

  • Content-Security-Policy (CSP) — obmedzuje zdroje skriptov, štýlov a sieťových spojení
  • X-Frame-Options: DENY — zabraňuje clickjacking útokom
  • X-Content-Type-Options: nosniff — zabraňuje MIME type sniffing
  • Referrer-Policy: strict-origin-when-cross-origin
  • Permissions-Policy — kamera, mikrofón a geolokácia explicitne zakázané
  • HTTPS vynútené Vercelom na všetkých doménach

7. GDPR a ochrana osobných údajov

  • Dáta sú uložené v EU regiónoch (AWS Frankfurt)
  • Prenosy dát mimo EÚ (OpenAI, Sentry) sú kryté štandardnými zmluvnými doložkami (SCC)
  • Cookie consent je implementovaný pred spustením analytiky
  • Spracovateľská zmluva (DPA) s Vercel a Supabase dostupná na vyžiadanie
  • Formálna Privacy Policy a DPA pre zákazníkov — odporúčame doplniť pre B2B klientov
