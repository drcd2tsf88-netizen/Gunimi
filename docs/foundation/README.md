# Gunimi Foundation

> Gunimi does not model software.
> Gunimi models business reality.
> Everything else — AI, workflows, interfaces, and automation —
> is simply a way of helping people understand and improve that reality.

---

## What this is

This directory contains the **constitutional layer** of Gunimi.

Not documentation. Not guidelines. Not best practices.

Laws that govern every decision at every layer of the platform — the database,
the API, the AI, the UI, and the roadmap.

If any implementation conflicts with a document in this directory, the
implementation changes. Never the foundation.

This is not aspirational. It is operational.

## The one question

When any decision feels unclear, return to this question:

> Does this reflect how business reality actually works,
> or does it reflect how the software was built?

If the answer is the latter, redesign the solution.
